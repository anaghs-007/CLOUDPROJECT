🧩 Context Tuple C(t) Breakdown C(t)
The formal 8-dimensional tuple captured per request:
  • u (Principal): User/Service Identity via JWT or Header
  • a (Action): HTTP verb (GET, POST, DELETE)
  • r (Resource): Target cloud API endpoint path
  • w (Workload): Owning application/compute instance
  • g (Geolocation): Request geographic region & IP CIDR
  • l (Sensitivity): Workload classification (public, internal, restricted)
  • ρu(t) (User Risk): Real-time logistic behavioral risk [0, 1]
  • ρw(t) (Workload Risk): Misconfiguration & exposure risk [0, 1]
